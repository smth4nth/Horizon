## [Open-Source Tutorial 'Deep Agents in Action' Released](https://aihot.virxact.com/items/cmqmbymfe00zisl4f3pa6jwmz) ⭐️ 6.0/10

An open-source tutorial titled 'Deep Agents in Action' has been released by LangChain ambassador @zhanghaili0610. It focuses on building real-world agent applications using the Deep Agents Harness framework within the LangChain/LangGraph ecosystem. This tutorial is significant as it provides structured guidance for developers looking to leverage the Deep Agents Harness framework to build robust AI agents. It can enhance the practical application of AI technologies in real-world scenarios. The tutorial is structured into 8 chapters and 2 preparatory sections, covering virtual file systems, task planning, asynchronous parallel sub-agent delegation, and skills reuse. It utilizes a 'three-layer architecture': Runtime (LangGraph), Framework (LangChain), and Harness (Deep Agents).

rss · AIHot · Jun 20, 12:16

**Background**: LangChain and LangGraph are part of a broader ecosystem designed to facilitate the development of AI agents. LangGraph provides a graph-based structure for non-linear workflows, while LangChain offers a framework for creating and managing these agents. The Deep Agents Harness framework integrates these components to provide a comprehensive solution for agent development, emphasizing context engineering to optimize AI performance.
